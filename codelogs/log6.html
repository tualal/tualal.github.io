Code Log 6 — DTC 355

What I Looked Up

I looked up display: grid — CSS Grid layout. I used it in my major project site (CutGuide) to build the two-column hero section on the homepage and the card grid that displays all nine topics. It felt like a good one to actually research since I was using it without fully understanding everything it could do.

The Four Resources

  1. W3Schools — CSS Grid
  2. MDN Web Docs — CSS Grid Layout
  3. CSS-Tricks — A Complete Guide to CSS Grid
  4. Learn CSS Grid — learncssgrid.com

Differences Between the Sites

W3Schools

The most beginner-friendly of the four. It breaks everything into short sections with live "Try it Yourself" editors so you can mess with the code directly in the browser. It doesn't go very deep but it's fast to scan when you just need a quick reminder of the syntax. Good starting point, not much beyond that.

MDN Web Docs

The most thorough by a lot. It covers not just the basics but also advanced stuff like subgrid, named grid areas, auto-placement, and how grid interacts with other layout methods like flexbox. It reads more like technical documentation than a tutorial, which can be a lot if you're just starting out, but it's the most complete reference of the four. I'd use this when I need to know exactly how something is supposed to behave.

CSS-Tricks

Their "complete guide" actually lives up to the name. What makes it stand out is the visual diagrams — every property has a clear illustration showing exactly what it does. It covers both the container properties and the item properties in one long scrollable page, which makes it easy to compare things side by side. It also gives context about why grid exists and how it compares to older layout approaches like floats.

Learn CSS Grid

Sits somewhere between W3Schools and CSS-Tricks. It's organized as a learning guide rather than a reference, so it walks you through concepts in a logical order. More visually clean than MDN but less comprehensive than CSS-Tricks. Good for learning grid from scratch, not as useful once you already know the basics and just need to look something up fast.

Code Sample — How I Used Grid in CutGuide

Here's the CSS I used to build the two-column hero layout on my major project site:

.hero {
  display: grid;
  grid-template-columns: 1fr 1fr;
  min-height: 86vh;
}

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 1.5px;
}

The hero uses two equal columns (1fr 1fr). The card grid uses auto-fill with minmax so cards automatically wrap to new rows depending on the screen width without needing media queries.

What a Good Reference Page Should Offer

Based on looking at all four, a good code reference page should have working code examples you can actually run or edit, clear visual diagrams for anything spatial or layout-related, a logical organization that separates basic use from advanced use, and a way to quickly jump to what you need without reading everything. Browser compatibility info is also useful — knowing whether something works across browsers matters when you're building for real.

Standouts

CSS-Tricks is the best of the four for CSS Grid specifically. The visual diagrams make the spatial concepts click in a way that reading code alone doesn't. MDN is the most technically accurate and complete, but I'd use it to look up a specific property rather than to learn from scratch. W3Schools is fine as a starting point but feels shallow once you've been working with grid for more than a few hours. Learn CSS Grid is a solid beginner resource but I probably wouldn't go back to it after getting comfortable with the basics.
