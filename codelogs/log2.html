CSS Measuring Units

Absolute vs. Relative Units

In CSS, there are two main types of measurement units: absolute and relative. Understanding the difference between them is important for creating good web designs.

Absolute units are fixed sizes that don't change. They are the same size no matter what. For example, if you set something to 100 pixels, it will always be 100 pixels wide. Common absolute units include pixels (px) and points (pt). These work well when you need something to be an exact size.

Relative units are flexible and change based on other things. They might be based on the parent element's size, the font size, or the screen size. Examples include em, rem, and viewport units like vw and vh. These are really useful for making responsive websites that work on different screen sizes.

The main difference is that absolute units stay the same size always, while relative units adapt to their context. Most modern websites use a mix of both, but relative units are generally preferred for responsive design.

Pixels (px) and Points (pt)

Pixels are probably the most common CSS unit you'll see. One pixel (px) represents one dot on the screen. When you write width: 200px;, you're saying "make this 200 pixels wide."

Pixels are really straightforward to use because they're predictable. If you set something to 50px, you know exactly how big it will be. This makes them great for things like borders, small spacing, and when you need precise control.

However, pixels have a downside - they don't scale well for accessibility. If someone needs larger text on their screen, pixel-based layouts won't adjust for them.

Points (pt) are another absolute unit, but they're mainly used for print styles, not web pages. One point equals 1/72 of an inch. You might see font sizes in points in programs like Microsoft Word, but on websites, we usually stick with pixels or relative units instead.

em and rem Units

The em and rem units are both based on font sizes, but they work a bit differently.

An em unit is relative to the font size of the parent element. So if the parent has a font size of 16px, then 1em equals 16px. If you set something to 2em, it would be 32px (16 × 2). The tricky part is that ems can compound - if you nest elements with em sizes, they multiply together, which can get confusing.

The rem unit (which stands for "root em") solves the compounding problem. It's always relative to the root element's font size (usually the html element), not the parent. Most browsers set the default root font size to 16px, so 1rem = 16px, 2rem = 32px, and so on.

I find rem units easier to work with because they're more predictable. They also help with accessibility because if a user changes their browser's default font size, everything scales proportionally.

Viewport Units (vw, vh, vmax, vmin)

Viewport units are based on the size of the browser window. They're really useful for making things that fill the screen or scale with the screen size.

vw stands for "viewport width" - 1vw equals 1% of the viewport's width. So 100vw means the full width of the browser window. Similarly, vh is "viewport height" - 1vh equals 1% of the viewport's height.

These are great for creating full-screen sections or hero images that always fill the screen, no matter what size the browser window is.

vmax and vmin are less common but still useful. vmax uses whichever is bigger - the viewport width or height. vmin uses whichever is smaller. This is helpful when you want something to scale consistently whether the device is in portrait or landscape mode.

For example, if your viewport is 1000px wide and 600px tall:

  • 10vmax would be 100px (10% of 1000px, the larger dimension)
  • 10vmin would be 60px (10% of 600px, the smaller dimension)

One thing to watch out for with viewport units is that 100vh can sometimes cause issues on mobile browsers because of the address bar. But overall, viewport units are really powerful for responsive design.

When to Use Each Unit

Here's my basic approach to choosing units:

  • Use px for small, precise things like borders or shadows
  • Use rem for font sizes and spacing to keep things consistent and accessible
  • Use em when you want spacing to scale with the font size of a component
  • Use vw/vh for full-screen sections or responsive typography
  • Use vmin/vmax when you need something to work in both orientations

Learning when to use each type of unit takes practice, but understanding the basics of absolute vs. relative units is a good starting point. As you build more websites, you'll develop a feel for which units work best in different situations.
