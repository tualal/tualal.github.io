CSS Media Queries

How CSS Media Queries Work and Why They're Useful

A CSS media query is basically a way to apply different styles to your webpage based on certain conditions, like the size of the screen or whether someone is viewing on a phone versus a desktop. They work by checking if specific conditions are true, and if they are, the CSS rules inside the media query get applied.

Without media queries, your website would look exactly the same on a phone as it does on a big desktop monitor, which usually means tiny text and awkward layouts on mobile devices. With media queries, you can make your navigation menu collapse into a hamburger icon on phones, adjust font sizes for readability, or reorganize your layout to work better on smaller screens.

For example, you might have a three-column layout on desktop that switches to a single column on mobile, or buttons that are small on desktop but bigger and easier to tap on touchscreens. Media queries make all of this possible without having to create completely separate websites for different devices.

Four Useful Media Features

1. max-width and min-width

The max-width and min-width features are probably the most commonly used media features. They check the width of the viewport (the visible area of the browser window) and apply styles based on whether it's above or below a certain size.

max-width means "apply these styles when the screen is this wide or smaller." For example, max-width: 768px targets screens that are 768 pixels wide or less, which typically includes tablets and phones. This is useful for making your layout more mobile-friendly.

min-width works the opposite way—it means "apply these styles when the screen is this wide or larger." This is useful when you want to add features or complexity only on bigger screens where there's room for them.

2. orientation

The orientation feature checks whether the device is in portrait mode (taller than it is wide) or landscape mode (wider than it is tall). This is especially useful for tablets and phones that can be rotated.

You can use this to adjust your layout when someone rotates their device. For example, you might show more content side-by-side in landscape mode but stack things vertically in portrait mode.

3. hover

The hover feature detects whether the device supports hovering, like with a mouse. Touchscreen devices don't really have "hover" since you either touch the screen or you don't, so this helps you avoid creating hover effects that won't work on phones and tablets.

This is useful because you can create fancy hover effects for desktop users with mice, but skip them entirely on touchscreens where they'd be frustrating or impossible to use.

4. prefers-color-scheme

The prefers-color-scheme feature detects if the user has their device set to light mode or dark mode in their system settings. This has become really popular lately as more people use dark mode to reduce eye strain or save battery on OLED screens.

You can use this to automatically switch your website to a dark theme when someone has dark mode enabled on their device, giving them a better experience without them having to manually toggle a theme switcher on your site.

Putting It All Together

Media queries are one of the most important tools for responsive web design. They let you adapt your site to different screen sizes, device capabilities, and user preferences. The key is thinking about how your design needs to change in different contexts and using media queries to implement those changes. Most modern websites use multiple media queries together to create layouts that work well everywhere from small phones to huge desktop monitors.
