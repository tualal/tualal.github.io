CSS Color

CSS Color Properties

CSS has three main properties for controlling color on web pages. The color property sets the color of text inside an element. The background-color property sets the background color behind an element's content, creating a colored box or area. The border-color property sets the color of an element's border, though you need to define a border width and style first for it to show up.

How CSS Accepts Color Values

CSS accepts colors in several different formats, and they all work the same way in your stylesheet.

Named Colors

You can use plain English color names like "red," "blue," or "coral." CSS recognizes 140 standard color names. These are simple to use but limited in options.

Hexadecimal Colors

Hex colors start with # followed by 6 characters representing red, green, and blue amounts. The format is #RRGGBB where values go from 00 to FF. For example, #ff0000 is pure red, #00ff00 is green, and #0000ff is blue. This gives you access to over 16 million colors.

RGB Colors

RGB uses numbers from 0 to 255 for red, green, and blue channels. It's the same concept as hex but written with regular decimal numbers. For example, rgb(255, 0, 0) is red, and rgb(0, 0, 0) is black.

RGBA Colors

RGBA is like RGB but includes a transparency value from 0 (fully transparent) to 1 (fully opaque). This is useful for semi-transparent backgrounds or overlays.

All these color formats work exactly the same in CSS, so you can use whichever one makes sense for your project. Named colors are quick and easy, hex codes are industry standard, RGB is intuitive with regular numbers, and RGBA adds transparency when you need it.
