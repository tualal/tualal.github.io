Images in HTML and CSS

HTML img Tag vs CSS background-image

The <img> tag is used for content images that are important to the page, like product photos or diagrams. These images are part of the document structure, require alt text for accessibility, and take up space in the document flow.

The CSS background-image property is for decorative images that enhance design but aren't essential content. These sit behind content, don't affect document flow, don't require alt text, and won't show up in search engines the same way.

Other CSS Background Properties

background-size: Controls how big the background image appears. Use cover to fill the entire element or contain to fit the whole image inside without cropping.

background-position: Determines where the image sits within the element, like center, top, or bottom.

background-repeat: Controls whether the image repeats. Use no-repeat to show it once, or repeat to tile it.

Dimensions vs Resolution

Dimensions refer to the width and height of an image in pixels, while resolution refers to how densely those pixels are packed together when displayed or printed.

Image File Formats (Extra Credit)

JPEG: Best for photographs. Uses lossy compression for small file sizes but no transparency support.

PNG: Best for graphics and logos. Supports transparency and uses lossless compression, but larger file sizes.

GIF: Best for simple animations. Limited to 256 colors, supports transparency, but poor for photos.

WebP: Modern format with better compression than JPEG/PNG. Supports transparency and animation with smaller file sizes, though older browsers don't support it.

SVG: Vector format perfect for logos and icons. Scales infinitely without quality loss but not suitable for photos.

Use JPEG for photos, PNG for graphics needing transparency, WebP for best compression with fallbacks, and SVG for logos and icons that need to scale.
