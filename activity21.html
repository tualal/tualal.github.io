Website Speed & Security Analysis

Tested: April 22, 2026  |  Mobile mode (Google PageSpeed)

Overview

This report analyzes three fitness and nutrition websites using four online testing tools: Google PageSpeed Insights, GTmetrix, Pingdom Website Speed Test, and Sucuri Website Security Check. All three sites target a similar audience — people looking for health, diet, and fitness information — which makes them a useful group to compare side by side.

All PageSpeed Insights scores were recorded using the mobile testing mode to reflect the experience for users on phones, which make up the majority of web traffic for this type of content.

Sites Tested

Bodybuilding.com https://www.bodybuilding.com
MyFitnessPal https://www.myfitnesspal.com
Healthline https://www.healthline.com

Observations

Bodybuilding.com was the weakest performer across the board. Its page size of 10.8 MB is enormous compared to the other two, and its 4.54 second load time reflects that. It also scored the lowest on PageSpeed performance (26) and was the only site to receive a D from GTmetrix. One note: PageSpeed redirected to shop.bodybuilding.com rather than the main site, so those scores reflect the shop subdomain.

MyFitnessPal was the fastest in raw load time (709ms) and had the smallest page weight (1.8 MB), which tracks — it's essentially a landing page pushing users toward the app rather than a content-heavy site. It scored highest on SEO (100) and had strong structure scores in GTmetrix (93%). It still failed Core Web Vitals on mobile, though, largely due to a slow LCP of 3.6 seconds.

Healthline was the only site to pass Core Web Vitals, which stands out given that its mobile performance score (35) was actually lower than MyFitnessPal's. This suggests its real-world user experience metrics are better than its lab scores imply — likely because it's a well-trafficked site with solid CDN infrastructure (Amazon CloudFront). The medium security flag from Sucuri is worth noting: the site loads some resources over HTTP instead of HTTPS, which is a fixable issue but a minor red flag.

All three sites are running on CDN infrastructure, which helps with global load times. None had malware or blacklist issues. The overall pattern is consistent with most large commercial sites — security is solid, but performance optimization (especially on mobile) is an ongoing challenge.
